# v0.6.1 — text contrast correction

Applies an explicit shared foreground/background palette to every screen and the report/cleanup review dialogs. Dark content surfaces use light text; buttons use dark text on a light surface. Native tab headers keep Windows system colors. Windows High Contrast colors are respected when opening the app/dialog.

Build and launch on Windows were confirmed by the user for v0.6. This theme patch is cross-compiled in Linux; visual verification on Windows remains outstanding. Check all tabs, nested tabs, filters, checkbox labels, enabled/disabled buttons, selected list rows and review dialogs. No diagnostic or cleanup behavior was changed.

Extract this source ZIP and run BUILD-WINDOWS.cmd again. Launch the new timestamped build's HankiTools.exe; its title shows v0.6.1.
