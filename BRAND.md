# Hanki visual identity

A snow-ridge H: two steady uprights connected by a rising diagonal. The mark is drawn as vector geometry in the app and included as an editable SVG. The multi-resolution ICO supplies the executable, taskbar and window icon. The wordmark uses lowercase Segoe UI Bold.

| Role | Color |

| Pine / content surface | #172728 |

Use ice mint for selected navigation and a small number of primary actions. Secondary buttons stay pine with snow text. The controls preserve native button semantics, keyboard activation, focus cues and a system-color High Contrast fallback. Native Windows dialogs remain controlled by Windows.

The desktop layout uses a permanent left navigation rail, one page heading, compact nested tabs, six tool cards on the overview and a quiet task-status footer. Colors signal interaction, not a machine-health verdict. No unmeasured health score is shown.

This is a new visual design, not a trademark or domain clearance.
